Prepare Here — .NET Interview Prep Tool
Data-driven UI

Problem: most interview-prep lists are static text — hard to search, impossible to track progress against, and painful to keep updated.

Decision: instead of hardcoding 100 questions into the page's JavaScript, I split content into a standalone XML data source that the page fetches and parses at runtime with DOMParser. New questions get added by editing one XML file — zero code changes needed.

Result: a searchable, filterable prep tool covering six backend domains (C#/.NET, ASP.NET Core, security, EF Core, SQL Server, architecture & testing), with per-question progress tracked in localStorage.

FileOrganizer
.NET 8 Console App

Problem: manually sorting hundreds of downloaded files by type was eating real time every week.

Decision: built a .NET 8 console app rather than a Windows Service — it needed zero admin install, was easier to debug during development, and Windows Task Scheduler already solved the "run this daily" problem without extra infrastructure.

Result: the app scans a target folder recursively, classifies files by extension, and organizes them into subfolders automatically on a schedule with no manual intervention.
